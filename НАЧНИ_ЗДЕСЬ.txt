НАЧНИ ЗДЕСЬ — Яндекс Алиса, GPT-6.1 Sol и Serper

ЕСЛИ ПРОЕКТ УЖЕ ПОДКЛЮЧЕН К VERCEL

1. Сохраните обновленный код в своем репозитории GitHub.
2. Откройте Vercel → проект → Settings → Environment Variables.
3. Проверьте переменные для окружения Production:
   OPENAI_API_KEY — ключ проекта OpenAI из организации с активными API-кредитами.
   SERPER_API_KEY — ключ Serper для поиска актуальной информации.
   OPENAI_MODEL — gpt-6.1-sol.
   OPENAI_REASONING_EFFORT — low.
   OPENAI_MAX_OUTPUT_TOKENS — 1200.
4. Если раньше была переменная GPT_MODEL, проверьте ее: она используется только при отсутствии OPENAI_MODEL. Ключи Gemini больше не нужны.
5. После сохранения переменных откройте Deployments → Redeploy для Production-развертывания. Дождитесь Ready.
6. В Яндекс Диалогах проверьте Webhook URL: HTTPS-адрес вашего Production-домена Vercel с путем /api.
7. Включите «Использовать хранилище данных в навыке».

ПРОВЕРКА ОТВЕТОВ

1. В Яндекс Диалогах откройте навык → Тестирование.
2. Отправьте «Почему небо голубое? Ответь одним предложением».
3. Если ответ еще готовится, немного подождите и скажите «Готово?» или «Дальше». Повторяйте команду, пока не получите ответ. Эти команды проверяют уже созданный запрос, не запускают генерацию заново.
4. После получения ответа спросите «А почему на закате оно красное?», чтобы проверить контекст.
5. Для проверки Serper отправьте «Найди последние новости космонавтики». Если понадобится, запросите результат командой «Готово?».
6. Для проверки отмены задайте новый вопрос и, если навык сообщил об ожидании, отправьте «Отмена». После подтверждения отмены можно задать другой вопрос.
7. Проверьте появление запросов в статистике OpenAI и Serper.

Приветствие не проверяет подключение к OpenAI: оно формируется самим вебхуком. Для проверки нужен обычный вопрос.

Для запуска опубликованного навыка скажите «Алиса, запусти навык Чипи Чапа». На устройстве должен быть аккаунт владельца приватного навыка или аккаунт с выданным доступом.

КАК РАБОТАЕТ ОЖИДАНИЕ

GPT-6.1 Sol готовит ответ в фоне на стороне OpenAI. Если результат готов сразу, Алиса озвучит его. Если требуется больше времени, навык сообщит об ожидании.

«Готово?» или «Дальше» — проверить и получить существующий ответ.
«Отмена» — отменить текущую генерацию в OpenAI.

Пока ответ готовится, новый вопрос не запускается: сначала получите предыдущий результат или отмените его.

Алиса не озвучит ответ сама без следующей команды пользователя. Оставайтесь в текущей сессии навыка и скажите «Готово?», когда будете готовы проверить результат. После выхода из навыка или начала новой сессии незавершенный запрос автоматически не восстановится. Выход из навыка не отменяет генерацию в OpenAI; для отмены перед выходом скажите «Отмена».

ЕСЛИ АЛИСА НЕ НАХОДИТ НАВЫК

Проверьте аккаунт Яндекса на устройстве, точное название, доступные устройства и публикацию навыка. В приложении попробуйте ввести «Запусти навык Чипи Чапа» текстом. Приватный навык не отображается в общем каталоге. Обнаружение навыка по имени и работа OpenAI — разные этапы.

ЕСЛИ ОТВЕТ НЕ ПРИХОДИТ

Проверьте имя модели gpt-6.1-sol, ключ OpenAI, API-организацию и кредиты. Убедитесь, что ключи заданы для Production и после изменения сделан Redeploy. Посмотрите логи Vercel.

Алиса ждет ответ вебхука не более 4,5 секунды. Код ограничивает обработку каждой реплики примерно 4 секундами, оставляя резерв на сеть; поиск Serper занимает не более 600 мс из этого времени. Модель может работать дольше в фоне: отдельные обращения создают запрос, проверяют его готовность или отменяют его. Увеличение лимита времени Vercel не меняет лимит Алисы.

Идентификатор текущего запроса, идентификатор последнего готового ответа и короткая резервная история передаются в состоянии навыка размером не более 1 КБ. Redis и отдельная база данных не нужны.

ДЛЯ НОВОГО ПРОЕКТА

Импортируйте свой репозиторий GitHub в Vercel через Add New → Project, разверните проект, затем выполните шаги настройки выше. Если получили ZIP, сначала распакуйте его и загрузите файлы в свой репозиторий GitHub, сохранив папку api и файл api/index.js.

API-ключи вводите в Vercel. Не добавляйте их в GitHub или сообщения. Node.js на личном компьютере нужен только для дополнительной проверки кода, а не для работы опубликованного навыка.
